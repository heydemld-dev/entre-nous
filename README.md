# ENTRE NOUS

Статический сайт бренда ENTRE NOUS, подготовленный для GitHub Pages.

## Локальный просмотр

Из папки репозитория:

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080`.

## GitHub Pages

В настройках репозитория откройте `Settings → Pages`:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

После первого тестового заполнения формы FormSubmit отправит письмо активации на `demi-go-d@ya.ru`. Подтвердите его, иначе заявки не будут пересылаться.

## Домен

В репозитории уже находится файл `CNAME` для `entre-nous.ru`. DNS-записи домена настраиваются после включения GitHub Pages.
